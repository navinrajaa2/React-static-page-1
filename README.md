## 📖 About the Project

**ReactFacts** is a beginner-friendly static page built using **React.js**. It presents a curated list of fun and interesting facts about the React library in a visually appealing dark-themed UI, complete with the iconic React logo.

This project is ideal for those learning the fundamentals of React — including component structure, JSX, and basic styling.


---

## ✨ Features

- ✅ Displays fun facts about React.js
- ✅ Dark-themed, modern UI design
- ✅ Features the official React logo as a visual element
- ✅ Built as a static single-page application
- ✅ Clean and minimal component structure — great for beginners
- ✅ Fast loading with Vite

## 🚀 Getting Started

Follow these steps to get **ReactFacts** running on your local machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Git](https://git-scm.com/)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/static-page1.git
   ```

2. **Navigate to the project directory**

   ```bash
   cd static-page1
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

### Running the App

**Development mode:**

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

**Production build:**

```bash
npm run build
```

**Preview production build:**

```bash
npm run preview
```
